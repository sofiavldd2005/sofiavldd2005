## About me

I'm Sofia, a soon to be Aerospace Eng graduate from Lisbon, heading into a
Master's in Electrical Engineering (or Compsi, have't decided that yet!). I like building software that lives close to
the hardware: flight computers, bootloaders, firmware, the whole
hardware-software frontier.

Being the **Electronics Co-Lead at [RED Rocketry](https://github.com/RED-PT)**,
thaught me to write flight software using FreeRTOS. Away from RED , my language
of choice is Rust 🦀 : bootloaders, `no_std` firmware, and my
[Leptos website](https://sofiavldd2005.github.io/). And when I'm not playing with Rust, I'm tweaking my NixOS + Neovim setup ahaha.
